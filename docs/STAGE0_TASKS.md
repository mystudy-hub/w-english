### 3.1 工程版本冻结动作

S0-01 执行并记录：

1. 以 Node 24 LTS 为基线；本次官网记录 24.21.0，当前工作区为 24.19.0，先确认是否统一升级或记录保留旧补丁的理由。
2. 固定 npm 版本、React/react-dom 18.3.1、Vite 8 与兼容的 React/PWA 插件；安装其余实现规格中的库并核对 peerDependencies。
3. 采用 save-exact，写 packageManager 与 package-lock；干净安装使用 npm ci。
4. 跑 typecheck、lint、production build；将结果附在工程基线记录。初次安装失败不能绕过锁文件手动混用多个包管理器。
5. 本地 PowerShell 若 npm.ps1 检查用户目录受限，可以使用安装目录中同一 npm 的 npm.cmd；不得为运行校验而修改用户全局权限。

### 3.2 校验实现边界

S0-02 的关键反例包括：null 条目、错误字段类型、spelling 写成整个单词、错误 track/stage、重复 ID、超长文本、未写批准时间。当前还已实现不存在的 clip、音频越界、空发布包、缺图、授权记录缺失、hash/bytes 错误、PCM和编码后解码检查；具体工程证据见最新核对记录。

测试重点是错误输入必须被拒绝，以及审核/版本/资源之间的约束；不为文案或简单 CSS 变更编写镜像测试。

## 5. 验收用例与证据记录

测试环境必须是生产构建。localhost 可用于自动 SW 测试；平板通过 HTTPS 地址访问。Safari 标签页与安装到主屏的应用分别联网预热，确认缓存完成后分别测试离线。

| 用例 | 操作步骤 | 必须观察到的结果 | 范围 |
|---|---|---|---|
| V00 内容与发布检查 | 校验 10 词/场景；故意替换为 draft 或断开的素材引用再打 release | 合格包通过；草稿/缺资源明确失败；preview 不冒充 release | 自动 |
| V01 首次手势解锁 | 新存储环境打开欢迎页，点开始，再播 cat/dog/cup；试听各类按钮 | 不提前自动播放；一次手势能开始；常速/慢速/音素引用正确 | 两台真机 |
| V02 连点与离开 | 连续点不同词/重播，声音中返回上一页 | 只留下当前请求；旧向导不追播；取消不记完整听过 | 两台真机 |
| V03 后台与中断恢复 | 播放中切后台 30 秒并锁屏，回来后再点喇叭 | 暂停期间不累计题目时间；处理 suspended/interrupted；恢复一次，不死循环 | 两台真机 |
| V04 浏览器离线冷启动 | 联网使全部必需文件 ready，飞行模式，真正关闭浏览器再打开同一地址 | 壳、图片、常速/慢速/例句/音素均可用；不依赖上一页内存 | 两台真机 |
| V05 主屏应用离线 | 安装/添加到主屏，在该容器联网打开并缓存，再飞行模式关闭重开 | 可用性同 V04；记录安装方式；不假定与 Safari 标签页共享存储 | 两台真机 |
| V06 下载中断 | 初次下载中断网；仅完成部分文件后重新联网/启动 | 不错误显示全包 ready；已校验文件复用；题目不引用缺失图/音频 | 自动 + 真机冒烟 |
| V07 更新保留旧包 | 准备 A 完整包；B 下载失败，再修复 B；保持一个会话活动 | 失败继续 A；B 完整后下个会话切换；不出现 A 词条引用 B 音频 | 自动 + 真机冒烟 |
| V08 SW 等待激活 | 在旧版学习页保持打开，部署新的壳；另开窗口再关闭全部旧窗口 | 使用中不刷新；有旧窗口时不强制接管；重开后新壳生效 | 两平台 |
| V09 存储缺失/不足 | 开发工具移除一个缓存键，模拟配额写入失败/IndexedDB 不可用 | ready 重新核实；可回退旧包；不清学习数据；家长看到可处理状态 | 自动；真机可控项 |
| V10 base 路径 | 根路径与 `/w-english/` 构建各预览，进入卡片并离线重开 | 图片、sprite、SW scope、hash 路由均正确 | 自动 |
| V11 基础体验 | 开系统减少动态效果；检查默认音量、静音与按钮键盘焦点 | 无循环跳动/粒子；cap 初值 0.7；可静音；主要控制可聚焦/触达 | 两平台 |
| V12 性能 | 按实施规格的包大小/响应/启动条件采样 | 原始数据可复核；未达预算记录原因和处理结果 | 两台真机 |
| V13 素材听审 | 老师在精灵最终编码产物上听 30 语音、14 音素，查看 10 图 | 无字母名混入、缺爆破音、额外元音、错图义、明显响度突变；有审批记录 | 老师 + 真机 |

### 5.1 测试记录模板

每次执行复制一行填写；结果只能写 `通过 / 失败 / 未测 / 不适用（说明原因）`。

| 用例 | 日期/测试人 | 设备/系统/浏览器/容器 | 应用提交与内容版本 | 结果 | 证据文件/问题编号 |
|---|---|---|---|---|---|
| 待填写 | 待执行 | 待登记 | 待构建 | 未测 | 无 |

证据保存在 `docs/qa/stage0/`（S0-08 创建），至少含设备清单、审批记录、网络/时间测量和问题复测说明。儿童相关记录到 Stage 1 使用匿名编号，不把姓名、照片或原始录音提交到仓库。

### 5.2 问题分级

- 阻塞：发音/拼读错误、无法开始或离线重开、存储丢失/重复记分、使用中强制刷新、关键控件不能操作。修复并复测前不进入下一阶段。
- 重要：明显超预算、恢复需要多余操作、可重复出现的提示/视觉问题。必须明确解决版本和验收结论。
- 一般：不影响闭环的轻微文案或装饰问题，可入后续清单。
